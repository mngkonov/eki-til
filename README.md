# Екі тіл

Личное приложение для изучения американского английского и казахского языка: уроки A1–C1 в игровом формате, уровни произношения с микрофоном, ИИ-собеседник, интервальное повторение, свои слова, статистика занятий.

Работает как веб-приложение (PWA): откройте сайт в Safari на iPhone → «Поделиться» → «На экран „Домой“».

Файлы:
- `index.html` — всё приложение в одном файле
- `manifest.webmanifest`, `icon-*.png` — иконка и полноэкранный режим
- `sw.js` — работа без интернета
